# CIS 285 Lab 6 - SplitSmart

This repository contains the Lab 6 documentation for the SplitSmart project.

## Purpose

SplitSmart is a shared-expense tracking application intended to help people manage expenses, groups, balances, approvals, and payments among individuals and groups such as friends, roommates, family members, and coworkers.
